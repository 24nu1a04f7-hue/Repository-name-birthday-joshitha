# Joshitha Birthday Website — Multi Page

The experience is now split into separate HTML pages:
1. index.html — opening
2. surprise.html — gift/surprise
3. gallery.html — photos
4. letter.html — friendship letter
5. cake.html — candles
6. finale.html — final message

Each stage redirects to a new page instead of continuing in the same page.

Music:
- `music/birthday-theme.wav` is included.
- Each page tries to autoplay it.
- Chrome may block autoplay after navigation; if that happens, click the round ♫ music button on the page. The button is the reliable browser-approved fallback.

Updated: premium animated cake page with glowing candles, balloons, hearts, sparkles, and expanded friendship letter.

Post-candle flow: cake.html -> wish.html -> finale.html.
